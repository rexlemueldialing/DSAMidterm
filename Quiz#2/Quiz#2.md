<h1>Visual Studio Code and Github: Installation, Set-Up, and Basic Operations<h1>

<h2>Visual Studio Code<h2>
<h3>A. Installation<h3>
<h5> Step 1. Download from microsoft website (options for windows and mac).<h5>
<h5> Step 2. Install the .exe file and simply click "next" for the following tabs.<h5>
<h5> Step 3. To verify if it is installed, just search in windows search bar.<h5>

<h3>B. Basic Operation: Opening VSCode through CMD<h5>
<h5> Step 1. Create a folder.<h5>
<h5> Step 2. Create a dummy file (e.g. “dummyFile.txt”).<h5>
<h5> Step 3. In the folder directory, type “cmd” and press enter.<h5>
<h5> Step 4. Once redirected to the Command Prompt, make sure that the directory is correct. Then type “code .” to open VSCode.<h5>

<h2>Git Hub<h2>

<h3>A. Installation of Git<h3>

<h5> Step 1. To Download Git, go to Git’s official website. For Windows, under “Standalone Installer”, choose x64 or ARM64 depending on your desktop’s architecture.<h5>
<h5> Step 2. After downloading, install Git.<h5>
<h5> Step 3. During the installation set-up of Git, simply click “next” for every step.<h5>
<h5> Step 4. To verify if Git is installed, select a folder > hit right click > show more options. You should now see the option “Open Git Bash Here”.<h5>

<h3>B1. Set-Up GitHub in VSCode<h3>
<h5> Step 1. First select View > Terminal > at the top right of terminal, click the dropdown > set to command prompt (still should be in the directory of desired folder).<h5>
<h5> Step 2. Next go to File > select "Auto Save”.<h5>
<h5> Step 3. Once finished, we can now download the necessary extensions. To download extensions, go to Extensions > search for  “Conventional Commits and Source Control” > Install both.<h5>
<h5> Step 4. To link VSCode to GitHub > go to Accounts > click “Backup and Sync Settings” > Sign in > select Sign in with GitHub > log in GitHub (make sure to use one email for easy linking).<h5>
<h5> Step 5. To verify if VSCode is linked to your GitHub, go to Accounts. Your GitHub account should be displayed at the very top.<h5>
<h5> Step 6. Lastly, To create a basic HTML code, hit right click > New file > enter file name (e.g. “helloWorld.html”) > write anything. To check if it worked, go to your file folder. The HTML file you just created should be saved there and runs once clicked.<h5>

<h3>B2. Set-Up Repository<h3>
<h5> Step 1. First, create a repository, go to Home > Create New Repository. In the New Repository Page, enter Repository Name (e.g. “DSAMidterm”) > set to Public > Create repository.<h5>
<h5> Step 2. Once a repository is created, go to codemy.com/git/ for setting up your source control (This is the standard way. Allows users to view who and what is edited or changes made in a file).<h5>
